## ✨ Features

- 🛡️ **100% Free & Zero Advertisements Forever**: Clean, modern light UI without pop-ups, banners, or tracking scripts.
- 🔄 **Persistent Mailbox Across Page Reloads**: Refreshing your browser (`F5`) keeps your active temporary email address and incoming messages intact.
- ⚡ **Live Automatic Auto-Sync**: Background listener checks for new incoming verification emails and OTP codes every 5 seconds with audio alert notifications.
- ☁️ **High-Deliverability Cloud MX Servers**: Instant reception of verification codes from Gmail, Google, Microsoft, Discord, Facebook, Instagram, and more.
- 🎨 **Custom Email Username Builder**: Create your own custom username (e.g. `yourname@bugfoo.com`) with 1 click.
- 📂 **Active Session History Panel**: Switch between up to 5 previously generated mailboxes in your session history without losing any verification messages.
- 📱 **Instant QR Code Mobile Sync**: Scan the QR code with your phone camera to view or copy the temporary email address on mobile devices.
- 🔒 **Sandboxed HTML Preview & Attachments**: Safe, isolated iframe rendering with Formatted HTML, Plain Text, and Raw Data views plus 1-click attachment downloads.

## 💻 Local Deploy & Run

To run or build **TempEmailo** locally on your machine:

```bash
# 1. Clone the repository
git clone https://github.com/Sk-Gaming-007/TempEmailo.git
cd TempEmailo

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev

# 4. Build single-file production bundle
npm run build
```

## 🚀 Free Deployment Guide

### Deploy on Vercel (Recommended)
1. Go to **[vercel.com](https://vercel.com/)** and click **Add New Project**.
2. Import `https://github.com/Sk-Gaming-007/TempEmailo`.
3. Framework preset: **Vite**.
4. Click **Deploy**.

### Deploy on Netlify
1. Go to **[netlify.com](https://netlify.com/)** and click **Add new site > Import an existing project**.
2. Connect your GitHub repository (`Sk-Gaming-007/TempEmailo`).
3. Build command: `npm run build` | Publish directory: `dist`
4. Click **Deploy Site**.

### Deploy on Cloudflare Pages
1. Go to **[pages.cloudflare.com](https://pages.cloudflare.com/)**.
2. Connect Git repository (`Sk-Gaming-007/TempEmailo`).
3. Build command: `npm run build` | Build output directory: `dist`.
4. Click **Save and Deploy**.
